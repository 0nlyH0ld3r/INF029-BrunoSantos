# Calcular a diferença em anos, meses e dias entre duas datas
 * Q2 = diferença entre duas datas

struct tempo {
	uint32_t dias;
	uint32_t meses;
	uint32_t anos;
	uint32_t codigo_retorno;
};

- Utilizando a mesma struct data da atividade passada.
- Utilizando as mesmas funções desenvolvidas na atividade passada.


## Retorno das funções

 * Retorna um objeto struct tempo. No campo **codigo_retorno**,
 deve ter os possíveis valores abaixo:
     * 1 -> cálculo de diferença realizado com sucesso
     * 2 -> datainicial inválida
     * 3 -> datafinal inválida
     * 4 -> datainicial > datafinal
     * Caso o cálculo esteja correto, os atributos qtdDias, qtdMeses e qtdAnos devem ser
     * preenchidos com os valores correspondentes.

## Entrada

 * Duas strings: char *d_ini, char *d_fim;
 
## Funções a se criar

- **struct tempo** calcula_tempo(**struct data** d1, **struct data** d2);
- **int** compara_data(**struct data** d1, **struct data** d2);

## Execução:

A ideia pra essa função é utilizar get_data para conseguir dois objetos struct data com as datas.

A função **compara_data()** deverá ser chamada dentro de **calcula_tempo()** para popular o retorno.
- **compara_data()** deve chamar **valida_data()** para determinar se a data é válida ou não.
    - Retorna 1 se não se encaixar em nenhuma das abaixo.
    - Retorna 2 se a primeira for inválida
    - Retorna 3 se a segunda for inválida
    - Retorna 4 se a segunda for maior que a primeira.
- **calcula_tempo** deve atribuir o valor dessa função à **struct tempo** que será retornada

A função **calcula_tempo** vai retornar uma struct limpa, somente com o código de retorno, caso ela se encaixe
em alguma das condições que não seja sucesso no cálculo.
