# Contagem de caracteres

O programa recebe um texto de até 250 caracteres e uma letra. O programa deve informar quantas
vezes essa letra aparece no texto.


Receber o texto de 251 caracteres, uma letra e uma flag de case sensitive.

Passar pelo texto inteiro buscando a letra e aumentando a contagem.

A busca deve poder alternar entre case sensitive e case insensitive.
